\section{Номер варианта}

Вариант: \Variant. В исходном задании отдельный номер варианта не указан.

\section{Цель работы}

Познакомиться с запуском MPI-программы на различном числе процессов,
обменом сообщениями между процессами и способами управления порядком вывода
результатов параллельного выполнения.

\section{Формулировка задания}

\textbf{Задание 1.} Все процессы, кроме процесса с рангом 0, передают
значение своего ранга нулевому процессу. Процесс с рангом 0 сначала печатает
значение собственного ранга, затем принимает сообщения с рангами остальных
процессов и также выводит их. Порядок приёма сообщений заранее не определён и
может изменяться от запуска к запуску.

Необходимо несколько раз запустить программу при фиксированном числе
процессов (например, при восьми), проанализировать порядок вывода сообщений и
сформулировать правило, которое его определяет.

\textbf{Задание 2.} Модифицировать программу так, чтобы порядок вывода
сообщений соответствовал номерам процессов. Сравнить результаты работы двух
вариантов программы.

\section{Предварительное описание решения}

Работу планируется выполнить на языке C с применением библиотеки MPI. Каждый
запущенный экземпляр программы является отдельным процессом. Число процессов
задаётся при запуске, а каждому процессу MPI назначает уникальный ранг от 0 до
$p-1$, где $p$ --- общее число процессов.

В первой версии процессы с ненулевыми рангами отправляют свои номера процессу
0. Нулевой процесс принимает сообщения от любого доступного отправителя. В
этом случае результат определяется тем, какое сообщение фактически будет
доставлено раньше, поэтому порядок рангов после нуля заранее не гарантируется.

Во второй версии нулевой процесс последовательно ожидает сообщения от
процессов 1, 2, \ldots, $p-1$. Благодаря явному указанию отправителя вывод
должен иметь порядок $0, 1, 2, \ldots, p-1$, даже если сообщения пришли в иной
последовательности.
