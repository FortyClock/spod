# Практические работы по системам параллельной обработки сигналов

## Практическая работа № 1

Предварительный отчёт находится в файле `report.tex`. В нём заполнены только
данные, которые не требуют запуска программы: тема, цель, формулировка задания
и предварительная идея решения. Ход работы и экспериментальные результаты пока
не добавлены.

Персональные данные для титульного листа задаются командами `\University`,
`\Department`, `\StudentName`, `\StudentGroup`, `\TeacherName`, `\City` и
`\Variant` в начале файла.

Для сборки нужен XeLaTeX:

```bash
xelatex report.tex
```

Команду рекомендуется выполнить дважды после появления оглавления, ссылок или
нумеруемых иллюстраций. Готовый документ появится в файле `report.pdf`.
